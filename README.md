# Distance Converter

A precision instrument for converting **kilometers** and **miles**.

Live demo: [https://reymundobermejo-glitch.github.io/Distance-Converter/](https://reymundobermejo-glitch.github.io/Distance-Converter/)

## Run locally

Open `index.html`, or:

```bash
python3 -m http.server 8080
```

## Features

- Live conversion as you type
- Swap source and result units
- Decimal precision 0–6
- Light and dark instrument themes
- Copy result
- Restoreable conversion history
- Race and road-trip presets
- Remembers theme, direction, precision, and history

## Formulas

- 1 mile = 1.609344 kilometers
- 1 kilometer = 1 / 1.609344 miles
